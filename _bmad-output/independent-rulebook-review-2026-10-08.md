# Gloam 룰북 독립 검토 — 2026-10-08

Gloam1.02 본문 60쪽, 공식 Combat Example 3쪽, Character Sheet 1쪽을 모두 읽고, 기존 앱의 코드·레이아웃을 보기 전에 실제 플레이 루프와 필요한 절차를 추출했다. 이 문서는 규칙의 분석 요약이며 원문 추출·전체 번역·표의 복제본이 아니다. 제공된 원문은 앱의 기존 보호된 reader에서 확인한다.

## 실제 플레이 루프

플레이어는 세 목표를 좇으며 허구 속 행동을 선언한다. 좋은 장비·충분한 시간·훌륭한 계획으로 가능한 일은 그대로 실행하고, 결과가 불확실할 때만 관련 능력치로 판정한다. 결과를 함께 해석하고 자원·부상·장비·관계를 갱신한 뒤 다음 행동으로 돌아간다. 본능·친구·적과 세션 뒤 세계의 반응은 이야기의 방향을 계속 바꾼다. 근거: p.4, 6, 8, 22–24.

일반 판정은 플레이어 카드와 실제 능력치·수정치를 더해 14 이상을 노린다. 한 명의 도움은 뽑기 전에 선언한다. 최초 성공과 문양 일치가 대성공이며, 첫 실패는 받아들이거나 한 번 밀어붙일 수 있다. 밀어붙여도 실패하면 대실패와 결의를 얻는다. 결의는 결과를 본 뒤에도 점당 +1로 사용할 수 있다. 플레이어가 결의를 얻을 때 심판도 얻으며, 소비 시 심판에게 전달되는 규칙은 없다. 근거: p.8, 14, 34.

탐사에서는 이동·소음·지체·극적인 순간에 사건이 필요하다. 반응이 불명확한 만남에서는 상호작용하는 플레이어가 반응 판정을 하고, 대화·약점 활용·회피·전투의 가능성을 살핀다. 사건과 징조는 지도 생성이나 비술 작성과 독립된 반복 도구다. 경점은 8시간, 차례는 15분, 라운드는 10초다. 인접 야외 구역의 이동은 한 경점이며, 모든 던전·정착지 이동에 같은 시간이 걸리는 것은 아니다. 근거: p.40–44, 50, 54–55.

## 전투와 피해의 순서

전투에는 단순한 전멸 외의 구체적 목표와 직교 격자 위치가 필요하다. 플레이어는 손패를 4장까지 보충하고 심판은 적마다 3장을 뽑는다. 기존 손패를 유지할 수 있다. 각자 선제권 한 장을 감추고 낮은 값부터 공개하며 행동한다. 선제권 값은 자신을 맞히는 판정의 목표치이기도 하다. 공식 예시는 심판의 전투 손패도 소 아르카나를 사용함을 확인해 준다. 근거: p.30, Combat Example p.1–2.

전투 판정은 새로 뽑거나 밀어붙이지 않고 손패를 사용한다. 일반 공격은 Swords 대 상대 선제권이며, 조준 및 대항 행동은 상대 능력치도 뺀다. 행동과 대응의 시점을 구분한다. 명중한 뒤 결의로 합계를 높이는 절차는 공식 예시에서도 반복된다. 근거: p.31, 34, Combat Example p.1–3.

일반 타격은 방어자가 신체 부위를 고르고, 조준은 공격자가 특정 부위를 노린다. 해당 위치의 온전한 AP를 빼고 남은 부상을 적용한다. 들어온 부상이 AP보다 크면 흠집 하나, 흠집 수가 원래 AP에 이르면 파손이다. 같은 갑옷 이름이라도 서로 다른 부위의 내구도를 합치지 않는다. 머리·몸통·팔·다리의 지속 효과와 괴수의 총 부상 한계를 함께 관리한다. 근거: p.27, 31–32, Combat Example p.2–3.

광대는 일반 상황의 두 덱 회수와 전투 라운드 끝 회수를 구분한다. 전투에서는 먼저 알리고 +3 또는 선제권 0으로 사용할 수 있다. 개별 사건·징조·비술 표에 명시되지 않은 결과를 앱이 임의로 만들지 않는다. 근거: p.7, 30, 38–39, 54–55.

## 반복 정보와 보조 작업

플레이 중에는 활성 목표·본능·인연, 실제 능력치·이동력·부상, 양측 결의, 해금 재능, 보유 무기의 부상·사거리와 갑옷 AP·흠집, 결과 옆 다음 선택이 가깝게 있어야 한다. 전투에서는 목표·손패·숨긴 선제권·행동/대응·적 상태·피해 순서를 함께 확인해야 한다. 원문 목차 순서를 그대로 라이브 화면 순서로 삼을 근거는 없다.

생성은 행로 → 능력치·천직 → 목표·본능 → 친구·적 → 다섯 무료 물품 순서다. 생성 뒤에는 단일 긴 폼보다 현재 상태와 단계별 편집이 적절하다. 휴식은 식사와 온전한 밤에 고른 부상 하나를 회복한다. 세션 시작 결의, 참여·목표 완수·위험의 최대 3 XP, 수련·고용·막간 계획은 낮은 빈도의 독립 절차다. 막간에서 완수한 목표의 결의는 다음 세션 시작에 받는다. 근거: p.9–16, 25, 35, 50–52.

## 자동화가 넘지 말아야 할 경계

- 반응 판정의 문양은 원문에 고정되어 있지 않다. 상황에 맞게 정한다.
- 비전 비술의 실제 효과는 단어를 심판과 해석한다. 전투의 적에게 영향을 주는 주문은 대항 Wands를 사용하며, p.38의 더 넓은 표현도 빠른 참조에 설명한다.
- Sally Forth는 라운드당 추가 행동 한 번이다. 원문에 없는 추가 판정 카드 지급 규칙을 발명하지 않는다.
- 괴수 재능·약점과 사건의 역방향은 구체적 서사 해석을 필요로 한다.
- 비술 물품에 쓰인 별도 표현을 일반 AP 수치로 임의 치환하지 않는다.

## 구현·검증 연결

기준선에서는 결의 획득/소비의 심판 변화, Major 카드 사기 계산, 전투 결과 후 플레이어 결의, 갑옷 경계·부위별 흠집, 오래된 궁정 카드 별칭 등 실제 규칙 오류를 찾았다. 최신 코드는 결의 함수, 전투 손패 경로, 반응 재능 +3, 부위별 갑옷 기록과 저장 이행, 막간 목표 보상의 다음 세션 지급, oracle 광대 이후 반복 판정 상태를 수정했다.
